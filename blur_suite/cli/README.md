# Blur Suite CLI

Command-line interfaces for the Blur Suite SDK, providing automation and command-line usage of the interactive blur configuration tool and dataset creation script.

## Overview

The CLI module provides two main tools:

- **Interactive Tool CLI** (`interactive`): Launch the GUI-based interactive configuration tool from the command line
- **Dataset Creation CLI** (`dataset`): Create blur/clear binary classification datasets using configuration files

## Installation

The CLI is included with the Blur Suite SDK. Make sure all dependencies are installed:

```bash
pip install -r requirements.txt
```

## Quick Start

### Basic Usage

```bash
# Show help
python -m blur_suite.cli --help

# Launch interactive tool
python -m blur_suite.cli interactive --image-dir ./documents/

# Create dataset from configuration
python -m blur_suite.cli dataset --config config.json --output ./dataset/
```

### Interactive Tool

The interactive tool provides a graphical interface for configuring blur effects on document images.

```bash
# Basic usage
python -m blur_suite.cli interactive --image-dir ./documents/

# With configuration file
python -m blur_suite.cli interactive --image-dir ./docs/ --config config.json

# Custom options
python -m blur_suite.cli interactive --image-dir ./docs/ --log-level DEBUG --theme dark

# Custom window size
python -m blur_suite.cli interactive --image-dir ./docs/ --geometry 1600x1000
```

**Options:**
- `--image-dir`: Directory containing document images to load on startup
- `--config`: Pre-existing configuration file to load
- `--output-config`: Where to save the generated configuration
- `--log-level`: Set logging verbosity (DEBUG, INFO, WARNING, ERROR)
- `--theme`: GUI theme selection (default, dark, light, blue, green)
- `--geometry`: Window size specification (e.g., 1400x900)

### Dataset Creation

Create blur/clear binary classification datasets using configuration files generated by the interactive tool.

```bash
# Basic dataset creation
python -m blur_suite.cli dataset --config config.json --output ./dataset/

# With parallel processing
python -m blur_suite.cli dataset --config config.json --output ./dataset/ --workers 8

# Performance tuning
python -m blur_suite.cli dataset --config config.json --output ./dataset/ --batch-size 50 --memory-limit 4GB

# Preview mode (dry run)
python -m blur_suite.cli dataset --config config.json --output ./dataset/ --dry-run

# Resume interrupted processing
python -m blur_suite.cli dataset --config config.json --output ./dataset/ --resume
```

**Options:**
- `--config`: Configuration file from interactive tool (required)
- `--output`: Output directory for the dataset (required)
- `--workers`: Number of parallel workers
- `--batch-size`: Images per batch for processing (default: 8)
- `--memory-limit`: Memory usage limit (e.g., 4GB, 500MB)
- `--resume`: Resume interrupted processing
- `--dry-run`: Preview what would be processed without creating files
- `--format`: Output image format (PNG, JPEG, TIFF)
- `--quality`: Output image quality/compression (1-100)

## Examples

### Example 1: Basic Workflow

1. **Launch interactive tool to create configuration:**
```bash
python -m blur_suite.cli interactive --image-dir ./document_images/
```

2. **Configure blur effects in the GUI and export configuration**

3. **Create dataset using the configuration:**
```bash
python -m blur_suite.cli dataset --config exported_config.json --output ./blur_dataset/
```

### Example 2: Batch Processing

```bash
# Process multiple configurations
for config in configs/*.json; do
    dataset_name=$(basename "$config" .json)
    python -m blur_suite.cli dataset \
        --config "$config" \
        --output "./datasets/$dataset_name/" \
        --workers 4 \
        --batch-size 16
done
```

### Example 3: Production Pipeline

```bash
#!/bin/bash
# Production dataset creation script

set -e  # Exit on any error

# Configuration
SOURCE_DIR="/data/documents"
OUTPUT_DIR="/data/datasets"
CONFIG_DIR="/data/configs"
WORKERS=8
MEMORY_LIMIT="8GB"

# Create output directory
mkdir -p "$OUTPUT_DIR"

# Process each configuration
for config in "$CONFIG_DIR"/*.json; do
    config_name=$(basename "$config" .json)
    output_path="$OUTPUT_DIR/$config_name"

    echo "Processing configuration: $config_name"

    python -m blur_suite.cli dataset \
        --config "$config" \
        --output "$output_path" \
        --workers "$WORKERS" \
        --memory-limit "$MEMORY_LIMIT" \
        --batch-size 32 \
        --quality 90

    echo "Completed: $config_name"
done

echo "All datasets created successfully!"
```

## Output Formats

### Dataset Structure

The dataset creation tool produces the following directory structure:

```
dataset/
├── train/
│   ├── clear/
│   │   ├── image1_clear_001.jpg
│   │   ├── image1_clear_002.jpg
│   │   └── ...
│   └── blur/
│       ├── image1_blur_001.jpg
│       ├── image1_blur_002.jpg
│       └── ...
└── test/
    ├── clear/
    │   ├── imageN_clear_001.jpg
    │   └── ...
    └── blur/
        ├── imageN_blur_001.jpg
        └── ...
```

### Image Naming Convention

- **Clear images**: `{original_name}_{index:06d}_clear_{augmentation_index}.jpg`
- **Blur images**: `{original_name}_{index:06d}_blur_{augmentation_index}.jpg`

Where:
- `original_name`: Stem of the original image filename
- `index`: Sequential number for the source image
- `augmentation_index`: Augmentation variant (0-2)

## Performance Tuning

### Memory Usage

```bash
# Limit memory usage
python -m blur_suite.cli dataset --memory-limit 2GB --batch-size 4

# High-performance settings
python -m blur_suite.cli dataset --workers 16 --batch-size 32 --memory-limit 8GB
```

### Processing Speed

- Increase `--workers` for more parallel processing
- Increase `--batch-size` for better throughput (uses more memory)
- Use `--memory-limit` to prevent out-of-memory errors

## Troubleshooting

### Common Issues

1. **Import Errors**
   ```bash
   # Make sure you're in the correct directory
   cd /path/to/blur-suite/

   # Check Python path
   python -c "import sys; print(sys.path)"
   ```

2. **Memory Issues**
   ```bash
   # Reduce batch size and workers
   python -m blur_suite.cli dataset --batch-size 4 --workers 2 --memory-limit 2GB
   ```

3. **Permission Errors**
   ```bash
   # Check directory permissions
   ls -la /path/to/output/directory/

   # Create output directory if needed
   mkdir -p /path/to/output/directory/
   ```

4. **GUI Issues**
   ```bash
   # Try different theme
   python -m blur_suite.cli interactive --theme default

   # Check display settings
   echo $DISPLAY
   ```

## Integration

### Shell Scripts

```bash
#!/bin/bash
# Example integration script

CONFIG_FILE="$1"
OUTPUT_DIR="$2"

if [ -z "$CONFIG_FILE" ] || [ -z "$OUTPUT_DIR" ]; then
    echo "Usage: $0 <config_file> <output_dir>"
    exit 1
fi

python -m blur_suite.cli dataset \
    --config "$CONFIG_FILE" \
    --output "$OUTPUT_DIR" \
    --workers 4 \
    --batch-size 16

if [ $? -eq 0 ]; then
    echo "Dataset created successfully: $OUTPUT_DIR"
else
    echo "Failed to create dataset"
    exit 1
fi
```

### Python Scripts

```python
#!/usr/bin/env python3
"""Example Python integration."""

import subprocess
import sys
from pathlib import Path

def create_dataset_with_cli(config_path: str, output_path: str) -> bool:
    """Create dataset using CLI."""
    try:
        result = subprocess.run([
            sys.executable, "-m", "blur_suite.cli",
            "dataset",
            "--config", config_path,
            "--output", output_path,
            "--workers", "4",
            "--batch-size", "16"
        ], check=True, capture_output=True, text=True)

        print("Dataset created successfully!")
        return True

    except subprocess.CalledProcessError as e:
        print(f"Failed to create dataset: {e}")
        print(f"Error output: {e.stderr}")
        return False

if __name__ == "__main__":
    success = create_dataset_with_cli("config.json", "./dataset/")
    sys.exit(0 if success else 1)
```
